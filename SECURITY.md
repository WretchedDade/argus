# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting:

1. Go to the [Security tab](https://github.com/WretchedDade/argus/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the affected version, and the steps to reproduce it.

You get a reply after the maintainer reads the report. Keep the details private until a fix is released.

## Report a bad release

A bad release is a release that contains a defect, a wrong file, or a file that was changed after it was built.

- If the release exposes a vulnerability or a secret, use private vulnerability reporting (see above).
- For all other problems, open a [GitHub issue](https://github.com/WretchedDade/argus/issues/new) and include the release version and the name of the archive.

Do not use a release that you think is bad. The maintainer can delete the release and publish a corrected version.

## Supported versions

Argus is on `0.x`. Only the latest release gets fixes.
